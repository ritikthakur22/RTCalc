## 3. Long Description
Welcome to **RTCalc**, a modern calculator built for simplicity, speed, and precision. Styled with an elegant interface and optimized for both Android phones and tablets, RTCalc makes everyday calculations effortless.

Whether you're performing standard arithmetic, scientific calculations, or currency conversions, RTCalc delivers instant, reliable results.

### Key Features
- **High-Precision Engine**: Built using robust decimal math logic to avoid standard floating-point calculation errors.
- **Scientific Calculator**: Support for trigonometry, logarithms, permutations, combinations, and angle unit toggling (DEG/RAD).
- **Currency Converter**: Instant exchange rate conversions with offline caching and global currency support.
- **Expression History**: Persistent history powered by Room. Search, restore, or clear your past calculations with one tap.
- **Adaptive Themes**: Seamlessly switch between Light, Dark, or System default modes.
- **Tactile Haptic Feedback**: Optional key vibration simulating mechanical responses.
- **Responsive Layout**: Designed for single-hand phone use and side-by-side tablet displays.

### Architecture & Tech
RTCalc is engineered using modern Android development practices: Jetpack Compose for UI, Room for local storage, Hilt for dependency injection, and DataStore for persistent settings.

## 6. Privacy Policy
RTCalc respects your privacy. All computations and calculation histories are stored locally on your device via an isolated SQLite/Room database. The application does not collect, track, or share any personal data.
